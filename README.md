# 🎮 Jogo da Velha em Python

Jogo da velha clássico (X e O) para dois jogadores, jogado direto no terminal.

# 📋 Funcionalidades
- Tabuleiro 3x3 interativo
- Validação de jogadas (impede jogar em posição ocupada)
- Detecção automática de vitória e empate
- Alternância automática entre os jogadores

# 🛠️ Tecnologias
- Python 3

## ▶️ Como rodar
git clone https://github.com/CarlosErnestoDev/jogo-da-velha-python.git
cd jogo-da-velha-python
python jogo_da_velha.py

# 🎯 Como jogar
As posições do tabuleiro vão de 0 a 8:

0 | 1 | 2
3 | 4 | 5
6 | 7 | 8

Digite o número da posição desejada quando solicitado.
